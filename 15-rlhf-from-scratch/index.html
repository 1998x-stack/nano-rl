RLHF: SFT → Reward Model → PPO

策略奖励不一定来自环境自带标量；RLHF 用成对偏好训练奖励模型，再以受约束的强化学习更新 SFT 初始化的语言策略。

三个训练阶段，一次贯通

1. SFT

把 prompt (a+b)%10 映射到一个候选 token，交叉熵学习示范答案。

2. Bradley–Terry RM

给定同一问题两个回答，拟合哪个更受偏好。

3. PPO + reference KL

在 RM 奖励上优化策略，惩罚离初始 SFT 模型过远。

偏好概率与 KL 惩罚演算

p(A ≻ B) = sigmoid(R(A) − R(B))
R_adjusted(A) = R(A) − β (logπ_old − logπ_ref)

什么会导致 Reward Hacking？

奖励模型学到的是有限偏好数据的代理目标，不等于任务真正质量。RL 优化可能发现奖励模型漏洞，因此需保留独立的真实任务评估，以及固定 reference 和 KL 约束。

本教学环境使用程序合成的偏好数据而不声称代表人类评价，也没有自然语言自回归生成。
