AlphaZero: PUCT + self-play

从 10 的多智能体学习转向对称、零和、自博弈：训练目标不是手工最优行动，而是树搜索的访问次数和最终输赢。

井字棋零和环境

点击棋盘落子。真实执行合法动作检查、三连线判断、换手视角；与 status / apply_move 对应。

PUCT 选择演算

score(a) = -Q_child(a) + c·P(a)√(Nparent+1)/(Nchild+1)

这里的先验 P 和访问数 N 是固定的**教学样例**，不是模型真实输出；只展示计算机制。

零和树中最常见的符号错误

孩子节点的 value 以下一个执手为视角，所以父节点评价要使用 −Q_child。终局标签为 z = winner × player_at_state。在 self_play() 与 mcts() 中都能看到对应逻辑。
