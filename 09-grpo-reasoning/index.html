组内相对优势

计算步骤

A_i = (r_i − μ_group) / (σ_group + 1e-4)

正优势奖励更好的组内候选；负优势抑制较差的候选。**只靠 0/1 奖励、当整组都对或都错时，学习信号变成零。**

与 PPO 的关系

GRPO 的核心不是神秘的新梯度：它仍可利用旧策略 log-prob ratio 和 clipped surrogate；差别之一是把单独价值网络的估计换为同一 prompt 的组内相对奖励。完整 LLM GRPO 还要考虑 token-level logprob、completion mask、KL 与采样版本一致性。

advantages = group_advantages(rewards)
surrogate, ratio = ppo_surrogate(new_logp, old_logp, advantages)
loss = -surrogate.mean() + beta * KL(policy, reference)
