Dreamer: Recurrent Stochastic World Model

MuZero 使用学得的模型去做有限树搜索；Dreamer 则在学习的世界模型内部生成想象轨迹，用这些轨迹更新 Actor-Critic。

RSSM：先验与观测后验为什么不同？

prior     p(z_t | h_t):  只使用历史与动作
posterior q(z_t | h_t,o_t): 可以看到当前真实观测
loss = reconstruction + reward + done + β·KL(q||p)

想象训练如何闭环？

用真实序列训练 q/p, decoder, reward, done；从观测后验初始化后，之后只在 prior 里滚动未来动作；用 λ-return 学习策略和值函数。训练代码刻意将 world model 优化与 imagined Actor-Critic 优化分为两个步骤。

页面密度曲线是上述公式的精确数值计算，不是声称完成了世界模型训练。
