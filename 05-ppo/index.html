Clipped Objective

r(θ) = π_new(a|s) / π_old(a|s)
Lclip = min(r A, clip(r, 1−ε, 1+ε) A)
loss_actor = −mean(Lclip)

训练代码的对应位置

utils.math.ppo_surrogate 精确实现 `minimum(ratio*A, clip(ratio)*A)`。

ratio = (new_logp - old_logp).exp()
surr1 = ratio * advantage
surr2 = ratio.clamp(1-eps, 1+eps) * advantage
loss = -torch.minimum(surr1, surr2).mean()

不要混淆

Clip 不是对 KL 散度的严格硬约束。 它对“有利于进一步改变该动作概率”的方向产生截断，却不直接阻止所有策略参数更新。

真实训练里，`old_logp` 来自本轮更新之前的行为策略，同一批数据只做有限次优化，之后必须重新采样，因此通常称为 On-policy。
